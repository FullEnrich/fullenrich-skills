# Security Policy

Report suspected vulnerabilities privately to [support@fullenrich.com](mailto:support@fullenrich.com). Include reproduction steps, potential impact, and relevant logs with credentials or personal data removed.

Do not disclose an unpatched vulnerability publicly. Wait until FullEnrich confirms that a patch or mitigation is available.

Security testing must use accounts, workspaces, and data that you own or are explicitly authorized to test. Do not access another customer's data, disrupt production, degrade service availability, or perform denial-of-service testing.

See the [FullEnrich Trust Center](https://fullenrich.com/trust) for security and compliance information.
